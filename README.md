# Cybersecurity Network Toolkit

## Overview
This project is a Python-based cybersecurity toolkit designed to demonstrate fundamental network security concepts including port scanning, network analysis, and password strength evaluation.

## Features
- Port Scanner (detect open ports on target systems)
- Network Information Tool (IP, MAC, system network details)
- Password Strength Checker (security level analysis)

## Technologies Used
- Python
- Socket Programming
- OS & Subprocess Modules

## Purpose
This project was developed to strengthen practical understanding of cybersecurity, ethical hacking concepts, and network behavior analysis.

## How to Run
python main.py
